# Сайт цветочного салона «ЛавФловер» (LoveFlower) — Черновой MVP

Черновой работающий MVP сайта цветочного салона «ЛавФловер» (LoveFlower).

Стек: **Python 3.9+ / FastAPI + Jinja2 + SQLite + Telegram Bot API**.  
Дизайн: **Минималистичный чёрно-белый стиль**, акценты — исключительно цвета букетов.

---

## 🚀 Быстрый старт

### 1. Подготовка окружения

```bash
# Переход в папку проекта
cd site

# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте шаблон `.env.example`:

```bash
cp .env.example .env
```

В `.env` можно указать реальные токен и chat_id для отправки заявок в Telegram:
```ini
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=-1001987654321
BASE_URL=http://localhost:8000
```
> **Важно:** Если токены не указаны, приложение работает в **режиме аккуратной заглушки**: заявка надёжно фиксируется в базе данных SQLite, логируется в консоль с полной HTML-разметкой для Telegram и не вызывает ошибок в интерфейсе.

### 3. Запуск сервера

База данных SQLite (`database/love_flower.db`) и 12 стартовых букетов инициализируются автоматически при первом старте сервера.

Запуск из директории `site/`:
```bash
uvicorn app.main:app --reload --port 8000
```

Или из корня репозитория:
```bash
PYTHONPATH=site uvicorn app.main:app --reload --port 8000
```

После запуска откройте в браузере: **[http://localhost:8000](http://localhost:8000)**.

## 🔍 Страницы и реализованный функционал

1. **Главная страница (`/`)**:
   - Минималистичный векторный логотип «ЛавФловер / LoveFlower» (кириллица в приоритете).
   - 5 кнопок быстрого входа по диапазонам бюджета:
     - *до 3 500 ₽*
     - *3 500 – 5 500 ₽*
     - *5 500 – 10 000 ₽*
     - *10 000 – 15 000 ₽*
     - *от 15 000 ₽*
   - Ссылка «Смотреть все букеты».
   - Витрина букетов «Можно сегодня» с экспресс-сборкой за 30–60 минут.
   - Блок преимуществ: выбор цветов за 5 минут без бесконечных согласований.

2. **Каталог (`/catalog`)**:
   - Фасетные фильтры через чипсы (Query-параметры):
     - **Бюджет**: Все / до 3500 / 3500–5500 / 5500–10000 / 10000–15000 / от 15000 ₽
     - **Размер**: Компактный (S) / Стандартный (M) / Большой (L)
     - **Палитра**: Нежная, Яркая, Монохром, Тёмная, Сезонная
     - **Наличие**: «Только в наличии сегодня»
     - **Сортировка**: по популярности, сначала дешевле, сначала дороже
   - Счётчик найденных композиций и кнопка сброса фильтров.
   - Сетка карточек с бейджами готовности, габаритами и кнопкой «Хочу такой».

3. **Карточка букета (`/catalog/{slug}`)**:
   - Крупное изображение, статус готовности, габариты, диаметр, срок сборки.
   - Описание букета от флориста и рекомендации по стойкости.
   - Кнопка «Хочу такой букет» с переходом на предзаполненную форму оформления.

4. **Форма заявки (`/order`)**:
   - Автоподстановка выбранного букета (или ручной выбор параметров: бюджет, размер, гамма).
   - Поля: Имя, Телефон (с интерактивной маской `+7 (XXX) XXX-XX-XX`), Дата, Временной интервал.
   - Способ получения: «Доставка по городу (такси)» с вводом адреса или «Самовывоз из салона».
   - Поле открытки / записки флористу.
   - Защита данных (чекбокс 152-ФЗ) и предупреждение о живом природном материале.

5. **Экран благодарности (`/order/success/{request_id}`)**:
   - Номер заявки `#LF-{request_id}`.
   - Детали заказа и уведомление о звонке менеджера Евгении в течение 10–15 минут.

6. **Доставка (`/how`)**:
   - Короткая понятная информация: самовывоз (ул. Солнечная, 11), доставка на такси, аквапак с водой.

7. **API (`POST /api/requests` и `GET /health`)**:
   - Поддерживает как стандартный form-submit с редиректом, так и асинхронный JSON API.
